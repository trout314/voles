    solve_vide

    solve_vide 

    solve_vide(*, kernel, a=None, g=None, y0, dt=1.0, coll_setting=None, quadrature='product', samples_per_interval=None, kernel_interp_degree=None, mesh=None, coll_nodes=None, kernel_singularity=None, reuse_adaptive_blocks=True)

    Solve a Volterra integro-differential equation.

    \[y'(t) = a(t)\, y(t) + g(t) + \int_0^t K(t-s)\, y(s)\, ds, \qquad y(0) = y_0\]

    by collocation: on each mesh interval \(y\) is a polynomial whose derivative satisfies the equation at the collocation nodes, continuous across the breakpoints.

    The inputs are either arrays of samples at \(t = 0, dt, 2\,dt, \ldots\) (the sampled regime) or callables (the functional regime, solved on the breakpoints mesh); see Notes.

    Parameters:

    Name Type Description Default
    kernel array_like or callable

    \(K\). Sampled: shape (N,), or (N, d, d) for a system of \(d\) equations, at \(u = 0, dt, \ldots, (N-1)\,dt\). Callable: kernel(u) returning a scalar or a (d, d) matrix; it may be vectorised over a 1-D u, which is faster.

    		 required
    a (array_like, callable or constant)

    \(a\). Sampled: (N,) or (N, d, d). Callable: a(t) returning a scalar or a (d, d) matrix. A constant, a number or a (d, d) array, works with either kind of input. Default zero.

    		 None
    g array_like or callable

    \(g\). Sampled: (N,), (N, d) or (N, d, m) for \(m\) right-hand sides. Callable: g(t) returning a scalar, (d,) or (d, m). Default zero.

    		 None
    y0 array_like

    \(y(0)\): scalar, (d,), or (d, m) for \(m\) initial values. A (d,) value is shared by all columns of a matrix g, and a (N, d) or (d,)-valued g by all columns of a (d, m) y0.

    		 required
    dt float

    Sampled inputs: the sample spacing. Default 1.0.

    		 1.0
    coll_setting int or (int, sequence of int)

    Sampled inputs: the collocation nodes choices / divs as (divs, choices), with choices in 0..divs, or a bare divs meaning every point 0..divs. divs also sets the mesh width (see samples_per_interval). Default (2, [0, 1, 2]).

    		 None
    quadrature ('product', 'collocation')

    Sampled inputs: how the integrals are evaluated from the samples. "product" (default) integrates a piecewise polynomial interpolant of the kernel exactly and accepts any mesh width and node set. "collocation" applies the interpolatory rule on the nodes; it is faster but fixes the mesh at divs**2 samples and runs only compiled settings (or the numba fallback).

    		 "product"
    samples_per_interval int

    Sampled inputs: samples per mesh interval. A multiple of divs with product quadrature (default divs); must be divs**2 with collocation quadrature.

    		 None
    kernel_interp_degree int

    Sampled inputs, product quadrature: the degree of the kernel interpolant. Default: the number of nodes.

    		 None
    mesh array_like

    Callable inputs: the mesh breakpoints, strictly increasing from 0 to \(T\). Required for callable inputs.

    		 None
    coll_nodes array_like

    Callable inputs: node positions in \([0, 1]\), e.g. voles.gauss_legendre_nodes(3). Default [0, 1/2, 1].

    		 None
    kernel_singularity (float, list, dict or callable)

    Callable inputs: where the kernel is weakly singular, in \(u = t - s\): a location, a list of locations, {location: alpha} for \(K \sim |u - u_0|^{-\alpha}\), or a callable returning the singular \(s\)-locations for a time \(t\). Declare the exponent when you know it: the blocks the singularity touches then use Gauss–Jacobi rules instead of adaptive quadrature, typically 3–10× faster for the whole solve.

    		 None
    reuse_adaptive_blocks bool

    Callable inputs: on a uniform mesh, reuse adaptive-quadrature blocks across mesh intervals. Default True.

    		 True

    Returns:

    Type Description
    VolterraSolution

    The solution: sol.t and sol.y on the input grid (the samples, or the mesh breakpoints), sol(t) anywhere in \([0, T]\), plus the collocation data and coefficients.

    Raises:

    Type Description
    TypeError

    An argument of the wrong type (a float where an integer is needed, a non-bool flag, a non-numeric array), or y0 missing.
    ValueError

    A wrong value: shapes that don't fit, an option from the other regime, an invalid node set, NaN or inf in the data, too few samples for one mesh interval.
    NotImplementedError

    Mixed callable and sampled inputs, or an uncompiled setting under quadrature="collocation" with no fallback.
    LinAlgError

    A collocation system is singular.

    Warns:

    Type Description
    AccuracyWarning

    A singularity declared on a uniform mesh.
    PerformanceWarning

    The numba fallback is used; or a declared exponent in kernel_singularity failed its accuracy check, so the singular blocks used adaptive quadrature.
    VolesWarning

    A kernel_singularity location outside \([0, T]\).
    See Also
    • solve_vie1, solve_vie2: the other two equations.
    • VolterraSolution: the returned object.
    • optimal_graded_mesh: a mesh for a weakly singular kernel.
    • gauss_legendre_nodes: node sets for coll_nodes.
    Notes

    The regime is chosen by the input types: arrays give the sampled regime (dt, coll_setting, quadrature, samples_per_interval, kernel_interp_degree apply), callables the functional regime (mesh, coll_nodes, kernel_singularity, reuse_adaptive_blocks apply). An option from the other regime is an error. Mixing callable and sampled inputs is not supported yet.

    Examples:

    Sampled data: \(y' = \int_0^t y(s)\,ds\) with \(y(0) = 1\) is \(y'' = y\), \(y'(0) = 0\), so \(y = \cosh t\).

    >>> import numpy as np
>>> import voles
>>> t = np.linspace(0, 1, 101)
>>> sol = voles.solve_vide(kernel=np.ones_like(t), y0=1.0, dt=t[1])
>>> print(f"{sol(1.0):.8f}  {np.cosh(1.0):.8f}")
1.54308063  1.54308063

    Callables: \(y' = -\int_0^t y(s)\,ds\) with \(y(0) = 1\) gives \(y = \cos t\). The solution is continuous, and its derivative comes from VolterraSolution.to_ppoly:

    >>> sol = voles.solve_vide(kernel=lambda u: -np.ones_like(u), y0=1.0,
...                        mesh=np.linspace(0, np.pi, 21))
>>> sol.continuous
True
>>> print(f"{sol(np.pi / 3):.4f}  {sol.to_ppoly().derivative()(np.pi / 3):.4f}")
0.5000  -0.8660

    def solve_vide(*, kernel: Data, a: Optional[Data] = None, g: Optional[Data] = None,
               y0: ArrayLike,
               dt: float = 1.0, coll_setting: CollSetting = None,
               quadrature: Quadrature = "product",
               samples_per_interval: Optional[int] = None,
               kernel_interp_degree: Optional[int] = None,
               mesh: Optional[ArrayLike] = None, coll_nodes: Optional[ArrayLike] = None,
               kernel_singularity: KernelSingularity = None,
               reuse_adaptive_blocks: bool = True) -> VolterraSolution:
    r"""Solve a Volterra integro-differential equation.

    $$y'(t) = a(t)\, y(t) + g(t) + \int_0^t K(t-s)\, y(s)\, ds, \qquad y(0) = y_0$$

    by collocation: on each mesh interval $y$ is a polynomial whose
    derivative satisfies the equation at the collocation nodes, continuous
    across the breakpoints.

    The inputs are either arrays of samples at $t = 0, dt, 2\,dt, \ldots$
    (the *sampled* regime) or callables (the *functional* regime, solved on
    the breakpoints ``mesh``); see Notes.

    Parameters
    ----------
    kernel : array_like or callable
        $K$. Sampled: shape ``(N,)``, or ``(N, d, d)`` for a system of $d$
        equations, at $u = 0, dt, \ldots, (N-1)\,dt$. Callable: ``kernel(u)``
        returning a scalar or a ``(d, d)`` matrix; it may be vectorised
        over a 1-D ``u``, which is faster.
    a : array_like, callable or constant, optional
        $a$. Sampled: ``(N,)`` or ``(N, d, d)``. Callable: ``a(t)`` returning
        a scalar or a ``(d, d)`` matrix. A constant, a number or a ``(d, d)``
        array, works with either kind of input. Default zero.
    g : array_like or callable, optional
        $g$. Sampled: ``(N,)``, ``(N, d)`` or ``(N, d, m)`` for $m$
        right-hand sides. Callable: ``g(t)`` returning a scalar, ``(d,)`` or
        ``(d, m)``. Default zero.
    y0 : array_like
        $y(0)$: scalar, ``(d,)``, or ``(d, m)`` for $m$ initial values. A
        ``(d,)`` value is shared by all columns of a matrix ``g``, and a
        ``(N, d)`` or ``(d,)``-valued ``g`` by all columns of a ``(d, m)``
        ``y0``.
    dt : float, optional
        Sampled inputs: the sample spacing. Default 1.0.
    coll_setting : int or (int, sequence of int), optional
        Sampled inputs: the collocation nodes ``choices / divs`` as
        ``(divs, choices)``, with choices in ``0..divs``, or a bare ``divs``
        meaning every point ``0..divs``. ``divs`` also sets the mesh
        width (see ``samples_per_interval``). Default ``(2, [0, 1, 2])``.
    quadrature : {"product", "collocation"}, optional
        Sampled inputs: how the integrals are evaluated from the samples.
        ``"product"`` (default) integrates a piecewise polynomial
        interpolant of the kernel exactly and accepts any mesh width and
        node set. ``"collocation"`` applies the interpolatory rule on the
        nodes; it is faster but fixes the mesh at ``divs**2`` samples and
        runs only compiled settings (or the numba fallback).
    samples_per_interval : int, optional
        Sampled inputs: samples per mesh interval. A multiple of ``divs``
        with product quadrature (default ``divs``); must be ``divs**2``
        with collocation quadrature.
    kernel_interp_degree : int, optional
        Sampled inputs, product quadrature: the degree of the kernel
        interpolant. Default: the number of nodes.
    mesh : array_like, optional
        Callable inputs: the mesh breakpoints, strictly increasing from 0 to
        $T$. Required for callable inputs.
    coll_nodes : array_like, optional
        Callable inputs: node positions in $[0, 1]$, e.g.
        ``voles.gauss_legendre_nodes(3)``. Default ``[0, 1/2, 1]``.
    kernel_singularity : float, list, dict or callable, optional
        Callable inputs: where the kernel is weakly singular, in
        $u = t - s$: a location, a list of locations, ``{location: alpha}``
        for $K \sim |u - u_0|^{-\alpha}$, or a callable returning the
        singular $s$-locations for a time $t$. Declare the exponent when you
        know it: the blocks the singularity touches then use Gauss–Jacobi
        rules instead of adaptive quadrature, typically 3–10× faster for the
        whole solve.
    reuse_adaptive_blocks : bool, optional
        Callable inputs: on a uniform mesh, reuse adaptive-quadrature blocks
        across mesh intervals. Default True.

    Returns
    -------
    VolterraSolution
        The solution: ``sol.t`` and ``sol.y`` on the input grid (the samples,
        or the mesh breakpoints), ``sol(t)`` anywhere in $[0, T]$, plus the
        collocation data and coefficients.

    Raises
    ------
    TypeError
        An argument of the wrong type (a float where an integer is needed, a
        non-bool flag, a non-numeric array), or ``y0`` missing.
    ValueError
        A wrong value: shapes that don't fit, an option from the other
        regime, an invalid node set, NaN or inf in the data, too few
        samples for one mesh interval.
    NotImplementedError
        Mixed callable and sampled inputs, or an uncompiled setting under
        ``quadrature="collocation"`` with no fallback.
    numpy.linalg.LinAlgError
        A collocation system is singular.

    Warns
    -----
    AccuracyWarning
        A singularity declared on a uniform mesh.
    PerformanceWarning
        The numba fallback is used; or a declared exponent in
        ``kernel_singularity`` failed its accuracy check, so the singular
        blocks used adaptive quadrature.
    VolesWarning
        A ``kernel_singularity`` location outside $[0, T]$.

    See Also
    --------
    - [solve_vie1][voles.solve_vie1], [solve_vie2][voles.solve_vie2]: the other two
      equations.
    - [VolterraSolution][voles.VolterraSolution]: the returned object.
    - [optimal_graded_mesh][voles.optimal_graded_mesh]: a mesh for a weakly singular
      kernel.
    - [gauss_legendre_nodes][voles.gauss_legendre_nodes]: node sets for ``coll_nodes``.

    Notes
    -----
    The regime is chosen by the input types: arrays give the sampled regime
    (``dt``, ``coll_setting``, ``quadrature``, ``samples_per_interval``,
    ``kernel_interp_degree`` apply), callables the functional regime
    (``mesh``, ``coll_nodes``, ``kernel_singularity``,
    ``reuse_adaptive_blocks`` apply). An option from the other regime is
    an error. Mixing callable and sampled inputs is not supported yet.

    Examples
    --------
    Sampled data: $y' = \int_0^t y(s)\,ds$ with $y(0) = 1$ is
    $y'' = y$, $y'(0) = 0$, so $y = \cosh t$.

    >>> import numpy as np
    >>> import voles
    >>> t = np.linspace(0, 1, 101)
    >>> sol = voles.solve_vide(kernel=np.ones_like(t), y0=1.0, dt=t[1])
    >>> print(f"{sol(1.0):.8f}  {np.cosh(1.0):.8f}")
    1.54308063  1.54308063

    Callables: $y' = -\int_0^t y(s)\,ds$ with $y(0) = 1$ gives
    $y = \cos t$. The solution is continuous, and its derivative comes from
    `VolterraSolution.to_ppoly`:

    >>> sol = voles.solve_vide(kernel=lambda u: -np.ones_like(u), y0=1.0,
    ...                        mesh=np.linspace(0, np.pi, 21))
    >>> sol.continuous
    True
    >>> print(f"{sol(np.pi / 3):.4f}  {sol.to_ppoly().derivative()(np.pi / 3):.4f}")
    0.5000  -0.8660
    """
    return _solve("vide", kernel=kernel, g=g, a=a, y0=y0, dt=dt, coll_setting=coll_setting,
                  quadrature=quadrature, samples_per_interval=samples_per_interval,
                  kernel_interp_degree=kernel_interp_degree, mesh=mesh, coll_nodes=coll_nodes,
                  kernel_singularity=kernel_singularity,
                  reuse_adaptive_blocks=reuse_adaptive_blocks)
